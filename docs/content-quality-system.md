# OpenDesign 内容质量体系 v1

## 产品立场

OpenDesign 不是网址收藏夹。它是设计总监 Agent 的证据层：只收录对设计判断、迁移和实施有真实价值的公开站点。

## 每日策展流程

```text
公开发现 / 用户提交
  → 来源与安全证据
  → 垃圾、广告、重复与仿冒检查
  → 设计价值 / 原创性 / 可复用性 / 证据完整性评估
  → AI 建议（approve / review / reject）
  → 人工确认或覆盖
  → 预览、规范、Pack、资产质量门
  → 进入发布准备队列
```

AI 决策必须记录：`decision_id`、候选、建议、置信度、原因、策略版本、模型、时间、各信号及证据。人工复核保留确认或覆盖状态、操作者、时间和覆盖理由。AI 建议不是最终发布权限。

## 硬拒绝规则

- 广告目录、联盟跳转、付费榜单或伪装下载占主体。
- SEO 垃圾、关键词堆叠、自动内容农场或批量重复落地页。
- 仿冒、钓鱼、恶意下载、可疑重定向或来源不可验证。
- 聚合或复制内容没有新增设计判断价值。
- 页面与设计参考无关，或无法提取布局、token、组件、交互、动效或叙事方法。

证据不足不等于垃圾；进入人工复核。可达不等于优质；流量不等于设计价值。

## 三轴与资产四件套

质量三轴保持独立：`evidence_tier`、`curation_status`、`origin_status`。不得合并成审美总分。

每条资源单独管理：Preview、Spec、Pack、Assets，状态为 `ready / missing / stale / failed / unknown`。后台应能定位缺失项并生成只读修复计划。

## 发布前门禁

- 人工最终确认存在。
- 原始 AI 建议与人工覆盖都可追溯。
- 预览、Spec、Pack、Assets 状态明确。
- 来源、采集时间、revision、授权或 reference-only 状态明确。
- 结构化规范通过 schema 与内容 QA。
- 公共页面、下载链接和 Agent 入口可用。
